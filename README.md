# Mergestorm Homebrew tap

```sh
brew tap marginsystems/tap
brew trust --formula marginsystems/tap/mergestorm
brew install marginsystems/tap/mergestorm
```

Installs the `mergestorm` CLI (also available as `mg`). The CLI is published on npm as [`mergestorm`](https://www.npmjs.com/package/mergestorm); source at [marginsystems/mergestorm-cli](https://github.com/marginsystems/mergestorm-cli).

Docs: https://mergestorm.ai/docs#cli-stacks
